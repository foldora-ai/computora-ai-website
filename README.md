# Computora AI website

Corporate homepage for Computora AI, the company behind Foldora AI, Cleanora AI, and Galoria AI.

## Development

```bash
npm install
npm run dev
```

Build for production with `npm run build`. The generated site is in `dist/`.

Product links point to the live product websites. The homepage assumes `https://computoraai.com/` as its canonical URL; update `index.html` if the final company domain differs.
